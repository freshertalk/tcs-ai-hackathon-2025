To use a recording of the mantra "Om Shri Ganeshaya Namah", put an MP3 in this
folder with exactly this name:

    shri-ganeshay-namah.mp3

It is picked up automatically; nothing else needs changing. Use a recording you
have the right to use (your own, or one you have licensed).

Without that file the browser speaks the mantra itself, in a Hindi voice when
the device has one.
